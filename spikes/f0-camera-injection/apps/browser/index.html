Chromium capture harness

This page is the 64-bit and 32-bit Chromium consumer for gate 1. It opens the virtual camera with getUserMedia, observes every frame the browser actually presents, records it with MediaRecorder, and uploads both the recording and the per-frame observation.

What is being measured

  • presented frames — one row per frame the browser presented, timed with requestVideoFrameCallback's presentationTime;
  • frame marker — the 20-block pattern in the top-left corner of the picture, decoded here from the canvas (the same geometry as spikes/tools/analysis/marker.py);
  • announced track settings — the size and rate the browser negotiated with the camera.
