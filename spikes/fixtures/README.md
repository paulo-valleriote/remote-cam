# Synthetic fixtures

Everything in this directory is **synthetic**. It contains no recorded human
speech, no real user media and no personal data. The fixtures are versioned for
the same reason test vectors are: two engineers must measure the same apparatus
with the same input.

## `calibration-40-60-120.wav`

The calibration capture for the audio dropout analyser and the toolchain
self-test.

| Property | Value |
| --- | --- |
| Sample rate | 48 000 Hz |
| Channels | 1 (mono) |
| Sample width | 16-bit PCM |
| Duration | 5.020 s |
| Content | Four voiced, formant-shaped synthetic bursts of 1.2 s each |
| Gap 1 | 40 ms of digital silence (below the 50 ms dropout criterion) |
| Gap 2 | 60 ms of digital silence (a dropout) |
| Gap 3 | 120 ms of digital silence (a dropout) |
| Expected result | Exactly **2** dropouts; the 40 ms gap is recorded as `below_threshold_intervals` |

The gaps are exact multiples of the 48 kHz sample period. The expected result
assumes the contract detector settings: a 5 ms RMS window, a `-50 dBFS`
threshold and a 50 ms minimum dropout.

`calibration-40-60-120.json` records the same provenance and layout in machine
form. The analyser reads the WAV; the JSON is there so the fixture can be
audited without opening the binary.

### Regenerating

```bash
python spikes/fixtures/tools/generate_calibration.py
```

The generator seeds every random draw, so it reproduces the committed file byte
for byte. The WAV is committed because it is small (about 471 KiB), synthetic
and part of the measurement apparatus; it is **not** a raw capture. Raw captures
produced by a gate run remain local-only (see `spikes/README.md`).

## `phrases-v1.csv`

The scripted intelligibility check. The observer reads every row in order and
records whether the phrase was heard exactly.

| Column | Meaning |
| --- | --- |
| `phrase_id` | Stable identifier, `P01`…`P20`. |
| `kind` | `anchor`, `static` or `nonce`. |
| `reference` | The exact English sentence the observer must hear. |
| `nonce` | The nonce word carried by a `nonce` row; empty otherwise. |

Composition, which the gate requires:

- **1 opening anchor** (`P01`) and **1 closing anchor** (`P20`) with identical
  text. They prove the observer was attending at both ends of the run.
- **8 static phrases** (`P02`–`P09`) of ordinary English.
- **10 nonce-bearing phrases** (`P10`–`P19`), each with a unique pronounceable
  nonce. A matched nonce proves the capture is not stale or spliced; a mismatch
  invalidates the run and it must be repeated.

The gate counts `phrases_exact` over the **non-anchor** rows only (18 of them)
and requires a corpus WER of at most 0.05.
